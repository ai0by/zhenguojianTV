## 关于

真果鉴TV 是一款**聚合多个短剧站源的 Android 播放器**。浏览、搜索、详情、选集、在线播放、下载与合并，全部在设备本地完成 —— 不需要注册登录，也没有任何自建服务器或中转节点。

- **站源解析在本地**：直接请求各站源接口，不经过第三方中转。
- **数据存在本机**：剧库、追剧、观看历史、下载记录都只留在你自己的设备上。
- **没有云端账号**：本机的「用户」只用来区分不同的使用者与权限。
- **无广告**：不集成广告 SDK，没有广告位、没有推广弹窗。

## 特性

| 模块 | 能力 |
| --- | --- |
| 浏览 | 首页竖滑刷剧；发现页分类、榜单、排序与筛选（名称 / 季号 / 上线日期 / 热度 / 播放量 / 连载状态）、VIP 过滤（黄豆）；多站源可勾选混合浏览 |
| 搜索 | 红果联网搜索 + 联想，黄剧在线搜索；**支持完整拼音与首字母**（`huangjin`、`hjdnz` 都能搜到「黄金大逆转」），纯本地词库，不依赖输入法 |
| 推荐 | 红果真人剧 / 漫剧 / AI 剧三条推荐流，可刷新、可继续刷 |
| 详情与选集 | 剧集资料、追剧、每 50 集一组翻页、输入集数直接跳转 |
| 剧库 | 后台自动更新（2 小时间隔，可关闭）+ 手动一键更新，补齐集数与简介；单轮限时，超时自动分批续跑 |
| 播放 | 竖滑切集、双击暂停、长按 3 倍速、自动连播下一集、清晰度 / 倍速 / 选集、全屏横屏手势 |
| 下载 | 批量下载、暂停 / 继续 / 重试、合并成分集视频、本地播放 |
| 导出 | 生成 Emby 可识别的目录结构与海报 |
| 局域网 | 两台设备之间同步追剧、把正在看的内容推到另一台播放 |
| 多用户 | 本机多用户，按用户开放站源与下载权限 |
| 外观 | 浅色 / 深色 / 跟随系统；手机与电视两套布局自动切换 |

## 安装

1. 到 [Releases](https://github.com/ai0by/zhenguojianTV/releases/latest) 下载安装包。
2. 手机首次安装需允许「安装未知来源应用」。
3. 打开即用。App 不检查更新，新版本请自行到 Releases 页面下载。

**选哪个包？**

| 包名 | 适合 |
| --- | --- |
| `-arm64-v8a.apk` | **绝大多数手机**（推荐，体积最小） |
| `-armeabi-v7a.apk` | 老款 32 位设备、部分电视盒子 |
| `-all.apk` | 不确定设备架构时用它，两种 ABI 都含 |

要求 **Android 7.0 及以上**。若提示 `INSTALL_FAILED_NO_MATCHING_ABIS`，说明装错了架构的包。

## 使用要点

- **手机**：上滑 / 下滑切集，单击显示控件，双击播放暂停，长按 3 倍速；全屏横屏后左半屏上下调亮度、右半屏调音量、中间上下切集。
- **电视 / 遥控器**：上下切集（刷剧模式下切剧），左右快退快进（按住连续），短按 OK 播放暂停、长按 OK 3 倍速，菜单键打开播放设置，返回键先收控件再退出。
- **没被识别成电视**（部分盒子、投影仪）：到「更多 → 界面模式」手动选「电视 / 遥控器」。
- 完整的按键、手势与常见问题见 [使用说明](docs/USAGE.md)。
