# 使用说明

真果鉴TV 的按键、手势与常见问题。安装与选包见 [README](../README.md#安装)，版本变化见 [更新日志](../CHANGELOG.md)。

## 手势速查

### 竖屏（手机）

| 操作 | 效果 |
| --- | --- |
| 上滑 / 下滑 | 下一集 / 上一集（首页为下一部 / 上一部剧） |
| 单击 | 显示 / 隐藏控件 |
| 双击 | 播放 / 暂停 |
| 长按 | 3 倍速，松开恢复 |
| 顶部约 60px 内滑动 | 交给系统（拉通知栏），不切集 |
| 右上角小窗按钮 | 进入系统画中画（边看边刷别的应用） |

画中画说明（0.8.17，仅手机）：播放中直接按 Home / 切到其他应用也会自动缩成小窗；暂停、报错或已经离开播放页时不会自动进入。电视端没有小窗概念，不提供该入口。

### 全屏横屏

| 操作 | 效果 |
| --- | --- |
| 左右滑动 | 调整进度（拖动时显示目标时间，松手生效） |
| 左侧 1/3 上下滑 | 画面亮度 |
| 右侧 1/3 上下滑 | 音量 |
| 中间 1/3 上下滑 | 上一集 / 下一集 |
| 单击 / 双击 / 长按 | 与竖屏一致 |

说明：亮度是**画面亮度**，不改手机系统亮度；音量是**应用内音量**，不是系统媒体音量。

### 电视 / 遥控器

| 操作 | 效果 |
| --- | --- |
| 上 / 下 | 刷剧模式上一部 / 下一部；单剧或「连播本剧」模式上一集 / 下一集。**焦点停在播放控件上时同样生效** |
| 左 / 右 | 后退 / 前进 10 秒；**按住连续快退 / 快进**（每次 5 秒） |
| 确定（OK） | 短按直接播放 / 暂停一次，同时显示控件并进入控件焦点；播放失败时直接重试 |
| **长按确定（OK）** | **3 倍速，松开恢复**（仅在控件收起时生效，避免和按钮点击冲突） |
| 菜单键 | 打开右侧「播放设置」：选集、倍速、清晰度、连播模式、追剧、详情与局域网推送 |
| 返回 | 控件可见时先收起控件；再按一次弹「退出播放」确认框 |
| 播放控件内 | 左右键在播放、倍速、清晰度、选集、追剧、连播之间移动；**上下键仍然是上一集 / 下一集**，**进度条不参与焦点**（快进用左右键）；电视没有全屏按钮 |
| 标题栏「站源」胶囊 | 按确定打开站源列表；上下移动、确定勾选，选好后移到「确定」再按一次生效 |
| 站源管理页 | 「更新 / 检测连接 / 更多」均可聚焦；「更多」打开居中列表而不是弹出菜单 |
| 搜索 | 弹窗自带屏幕键盘（遥控器可输入），另有「热门搜索」直接选片名；有输入法的设备仍可用系统键盘 |
| **拼音搜索** | 敲 `hjdnz` / `hdz` / `huangjin` 都能搜到「黄金大逆转」；词组多音字优先按实际读音处理，手机端同样生效 |
| 返回（首页 / 发现 / 追剧 / 最近观看） | 逐层退让：退出选择 → 退出推荐分类 → 回首页（左侧菜单焦点一并回到「首页」）→ 清空搜索 → 提示「再按一次返回退出」 |

说明：电视首页是**横向海报行**（继续观看 / 热门短剧 / 分类），不是手机的竖滑流；想随便刷剧就按第一行的「开始刷剧」，竖滑流会以独立页面打开。电视模式会自动隐藏手机专属交互（底部标签栏改为左侧导航），并在整个界面留出过扫描安全边距，避免贴边内容被电视边框裁掉。

### 电脑（Windows 版，源码保留）

播放画面获焦时：空格播放 / 暂停，左方向键后退 5 秒，右方向键轻按前进 5 秒、长按临时 3 倍速，上下方向键调音量，M 静音，F / F11 全屏，Esc 退出全屏或返回。

## 常见问题

**Q：怎么更新到新版本？**

A：打开「关于真果鉴TV」，点「检查更新」。有新版会显示版本号，点「下载并安装」即可。**应用不会自动检查、也不会弹窗提醒** —— 不点就永远不联网。下载会先给每个加速节点测速、挑最快的那个，能分片的还会开 4 条连接同时下；界面会显示实时速度和当前节点，连续 20 秒没数据、或者 12 秒内平均低于 12 KB/s 就自动换节点。**关掉对话框下载不会停**（挂在后台的下载器上），重新打开能看到进度，下完直接点「安装」。装之前会校验 sha256，校验不过的文件会被直接删掉。如果系统提示「不允许安装未知应用」，按提示去授权页打开开关，回来再点一次。电视盒子没有触屏，建议直接在浏览器里下安装包。

**Q：为什么剧库更新要很久？**

A：更新需要逐部复查详情。红果 2600 多部约 11 分钟、黄果 AI 2200 多部约 18 分钟，而单轮上限 10 分钟，所以会分批续跑。后台自动更新为 2 小时间隔、可关闭；手动更新随时可执行。

**Q：第一次打开，剧库为什么这么快就有内容了？**

A：剧库有一份**共享快照**。仓库的 `catalog` 分支由 CI 抓一轮、加密后提交上去，App 可以从 CDN 拉这份快照打底，不必自己现场跑一轮。抓取节奏是**定时只做增量**（每 6 小时只翻前几页拿新剧，与上一轮按 id 合并），**全量重抓（整站翻到底、跑 3 轮取并集、顺便清掉下架剧）只在需要时手动触发** —— 十几个站源一天翻一遍到底太像爬虫，容易被站源风控盯上，所以不放进定时任务。**0.8.20 起客户端改成手动同步**：进首页不再自动拉，去「设置 → 站源管理 → 同步远程数据源」点一下才同步，按钮下面会显示远端那份数据的生成时间（例如「11/2 15:29 · 14 个站源 / 119219 部 · 本机已同步」）。

只想补某一个站源，就点那张站源卡片上的「**同步远端**」（卡片上还会写「远端快照：38349 部」）—— 只为野果补一次，不必把网果的三万八千多部重下一遍。顶部按钮仍然是全部启用站源。同步完首页立刻刷新。拉不到（离线、CDN 不通）就照旧现场抓取，功能不受影响。加密只是避免目录被随手拖走，**不是安全边界** —— 密钥随安装包分发。

**注意流量**：整份快照 14 个站源约 42MB，只下你启用的那些。只开红果约 4.4MB；网果 / 无果各自 11MB，建议在 Wi-Fi 下补。

**Q：站源管理里黄果那三个入口，为什么以前看着是一大块空白？**

A：那是界面问题，不是网络问题。黄果是「剧场 / AI / 旧版」三个入口，原先被渲染成卡片套折叠面板再套卡片的嵌套结构，里外同一个底色，展开后看不出卡片边界，就像一块空白。0.8.20 已改成一行分组标题 + 三张独立卡片。远端快照里这三个入口一直有数据（AI 3138 部、剧场 1206 部、旧版 393 部）。

**Q：红果有时「突然什么都点不动」，过一会儿又自己好了？**

A：这是 0.8.21 之前的一个自伤行为，不是站点真的封了你。红果 App 接口的签名是每次现算的，服务端没认这套签名时回的是 403，换一套重试通常就过；旧版本把这类 403 当成「站点在拦我们」，给这个域名挂上 1~30 分钟的本地退避，于是接下来十几分钟里同一域名下的详情、取流、弹幕全都在发出去之前就被自己拦掉了。0.8.21 起这类 403 只当作签名失配处理：就地清掉退避、换签名重试，只有真的 429 限流才停手。另外单次请求也加了预算（普通 25 秒、弹幕 15 秒），不会再一路拖满一分钟才报错。

**Q：红果点开一集要等十几秒才出画面，但最后能播？**

A：0.8.27 已经重写了这段。查下来跟视频数据本身无关 —— 片源首包直连只要 100~230ms，慢的是「问服务端要播放地址」这一步：上游现在的规矩是**一个注册身份只能成功取流一次**，用过之后按身份屏蔽。旧逻辑不知道这件事，一直在同一个身份上做 0.8/1.4/2.0/2.5 秒的递增退避重试，最后靠外层碰巧重注册到一个新身份才出片，十几秒基本全在空等（实测 p50 12.49s、最坏 17.59s）。现在每取一集就注册一个新身份、首发就走官方现行的 `video_tab` 接口，单发不中就换路径而不是等；构建前两轮真实剧实测都是 12/12，p50 约 0.85 秒、最大 1.2 秒。同一集 10 分钟内再打开直接读缓存，几乎零等待。

**Q：提示「红果暂时取不到这一集的片源」，点一下重试又好了？**

A：这说明失败是瞬时的 —— 取流接口某一刻返回了一份没有播放信息的响应，隔几百毫秒再问一次就有了。0.8.27 起这类情况收敛成可静默重试的瞬时错误：播放取流自己换一个全新身份再试一次首选路径，前端还会再静默重来一次整轮解析，多数时候你只会觉得「这一集切得慢一点」。注册接口偶发抖动也不会再被硬判成「设备注册失败」—— 第二轮会重新注册。真的取不到（剧集已下架、网络确实不通）才会亮错误，那时候换一集或稍后重试才有意义。

**Q：黄果几个源有时更新失败？**

A：属网络可达性问题，不是解析错误 —— 黄果视频走 IPv6 且无备用域名，黄果 AI 的镜像域名会被重置。换网络或开代理后重试通常能恢复。

**Q：调了亮度，手机屏幕亮度没变？**

A：设计如此。只调整视频画面亮度，不动系统亮度，退出播放器后手机亮度不受影响。

**Q：为什么有的剧集没有「共 X 集」？**

A：部分站源的列表接口本身不返回集数（例如野果只给「最新一集」的 id），要拿到集数得逐部请求详情，代价太大，所以这些源只显示标题与封面。

**Q：支持电视 / 电脑吗？**

A：Android TV 已适配：遥控器导航、电视布局、过扫描安全边距、32 位盒子支持。Windows 版源码保留但当前不构建、不交付。

**Q：需要登录吗？**

A：不需要。没有云端账号；本机用户管理只用于区分不同使用者与权限。

**Q：预缓存占多少空间？会一直变大吗？**

A：不会。播放时会顺手把后面几集的分片存到本机（默认 2 集），所以切下一集不用等加载。缓存有容量上限（默认 1GB）和 7 天有效期，超过上限会自动淘汰最久没看过的内容。想改集数或上限、或直接清空，到「设置 → 播放预缓存」；清理只删预缓存，不影响已下载的剧集。

**Q：黄豆、黄剧、黄果、51、野果这几个站源去哪了？**

A：它们归在「黑洞站源」里，默认不展示。到「设置 → 黑洞站源」点进去，输入口令 `github-zhenguojianTV` 后这五站才会出现在站源列表里；开启之后想关掉，直接把那一条的开关拨回去即可，不用再输口令。关闭时只是不展示、不抓目录 —— 已经下载的、历史记录里指向这些站的剧集仍然能播。

**Q：香蕉站源去哪了？**

A：站点侧目前不给客户端返回剧集列表，客户端各种兜底都试过仍拿不到数据，所以暂时下线、入口不再展示。等站点恢复会重新放出。

**Q：青空站源去哪了？**

A：0.8.25 起隐藏了。上游强制登录 + 验证码，客户端绕不过去，播放恒报「该分集暂无可用播放地址」，留着入口只会让人以为这个源坏了。**只是隐藏，没有删除**：代码与已下载内容都还在，历史记录、收藏里指向青空的剧集照常能播。

**Q：排行榜只有红果/黄豆/黄果吗？**

A：0.8.25 起扩到 9 个站源 23 个榜单：红果（总热播 / 真人 / 漫剧 / AI）、黄豆（总 / 魔改 / 搜索 / 收藏 / 完结）、黄果（热播 / 推荐 / 潜力）、黄剧（热播 / 最新）、51（总 / 周 / 月）、E站（新番榜）、网果（排行榜）、发果（短剧 / 动漫月榜）、囧次元（日漫 / 剧场）。榜单页左上角切站源、下方切同一站源的不同榜单。黑洞站源关闭时，它们的榜单也不会出现。

**Q：弹幕有时候不显示？**

A：弹幕只有红果源有，而且**弹幕永远只是辅助** —— 拉不到弹幕不会影响视频播放。0.8.22 起这条提示**不会一失败就出现**：同一段连续失败两次才会显示「弹幕加载失败 · 点击重试」（第一次失败只在后台静默重试，多数情况一两秒后自己就好了）。点一下就会立刻重取；不点也行，后台会按 1.2/2.4/4.8/9.6/15 秒的节奏继续重试，暂停或缓冲时也不会停。切集时第一窗弹幕会提前预取好，不会再出现「画面动了、弹幕过两秒才飘出来」。**整集没有弹幕数据的冷门剧、片头片尾这种确实没人发弹幕的片段，都不会再被误判成加载失败。**

**Q：红果搜索搜不到东西？**

A：红果只支持**按剧名匹配**，而且一次最多返回 20 条。用两三个字的短词容易搜不到，换成更完整的剧名（比如「XX的总裁」而不是「总裁」）成功率更高。红果网页端的「综合搜索」页面在 2026 年 11 月实测已彻底失效，客户端不再尝试它。
